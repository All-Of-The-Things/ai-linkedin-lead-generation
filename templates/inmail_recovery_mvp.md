## Style guide

- Subject: specific outcome, no teaser — "Spec-to-product build partner", "Fast build partner for internal tools", "AI-assisted build, spec to product"
- Body opens "Hi {{first_name}}." then leads directly into the builder-to-builder offer — fold AOTT into that clause rather than a separate self-intro. Never open with "I'm with AOTT".
- Lead with the same core angle as the connection note: builder-to-builder, Spec-driven (capital S), AI-assisted development, speed without scope drift
- "My Team" (capital T always)
- Reference at most one proof-of-work product (Scorestack, StoreSync, Bridge) if clearly relevant
- Target 180-230 chars for the body — the 1900-char cap is not a target.
- Never use em-dashes
- End with a specific, low-friction ask: "Worth a quick call?", "Open to a chat this week?"

## Two buyer types — same detection as the connection note

- **Type A (founder building a commercial product)**: speed from Spec to working product, no scope drift
- **Type B (internal tool need)**: turning a repeating manual process into a working tool quickly

## Banned phrasings

Same bans as `connection_note_mvp.md`, plus no reference to the invite, withdrawal, or "following up"/"reaching out again".
